# Array Sum

Given an array A of N integers, output the sum of all elements.

## Input
- Line 1: integer N
- Line 2: N space-separated integers A[0..N-1]

## Output
- Single line: the sum (fits in long long).

## Constraints
- 1 ≤ N ≤ 100,000
- 1 ≤ A[i] ≤ 10^9

## Sample
Input:
```
3
1 2 3
```
Output:
```
6
```
